# 🧰 Nivel 2 — Manipulación y Análisis de Datos

Este nivel corresponde a la etapa donde se empieza a trabajar con **datos reales**, pasando de estructuras básicas de Python hacia procesos más cercanos al trabajo de un analista de datos.

El objetivo principal es aprender a **obtener, limpiar, transformar, analizar y comunicar información mediante datos**, utilizando herramientas fundamentales como Pandas, NumPy, SQL y librerías modernas de visualización.

---

## 🎯 Objetivo del Nivel

Desarrollar habilidades para:

- Manipular conjuntos de datos reales.
- Realizar procesos de limpieza y transformación.
- Trabajar con DataFrames y operaciones vectorizadas.
- Analizar información mediante agrupaciones y métricas.
- Consultar datos utilizando SQL desde Python.
- Crear visualizaciones claras y orientadas a la interpretación.
- Comunicar hallazgos mediante storytelling con datos.

Este nivel representa la transición desde la programación básica hacia el **análisis de datos aplicado**, preparando la base para Machine Learning y proyectos profesionales posteriores.

---

# 📘 Contenidos Aprendidos

## 🔹 Pandas y NumPy

- Series y DataFrames.
- Carga de datos desde diferentes fuentes:
  - CSV
  - Excel
  - APIs
  - Bases de datos
- Exploración inicial de datasets.
- Limpieza y transformación:
  - Valores faltantes.
  - Duplicados.
  - Conversión de tipos de datos.
  - Manejo de fechas.
- Selección y filtrado de información.
- Indexación de datos.
- Agrupaciones y agregaciones:
  - `groupby`
  - métricas estadísticas
- Operaciones vectorizadas con NumPy.

---

## 🔹 Visualización y Comunicación de Datos

- Principios básicos de visualización.
- Gráficos estadísticos con Matplotlib.
- Visualización exploratoria con Seaborn.
- Visualizaciones interactivas con Plotly:

  - Gráficos de líneas.
  - Gráficos de barras.
  - Distribuciones.
  - Comparaciones temporales.

- Storytelling con datos:
  - Selección correcta de gráficos.
  - Interpretación de resultados.
  - Comunicación de hallazgos.

---

## 🔹 SQL Aplicado a Ciencia de Datos

- Conceptos básicos de consultas SQL.
- Integración de SQL con Python.
- Uso de DuckDB / SQLite.
- Consultas:

  - SELECT
  - WHERE
  - GROUP BY
  - ORDER BY
  - JOIN
  - Agregaciones

- Análisis de datos utilizando SQL + Pandas.
